# ローカル映像素材の棚卸し

実GoPro映像は、まず手元のストレージだけで棚卸しする。棚卸し処理は動画を
開いて内容を解析せず、外部ネットワークにも接続しない。作成されるJSONには、
相対パス、ファイル名、拡張子、ファイルサイズ、更新時刻だけが入る。絶対パス、
GPS、座標、映像フレーム、音声、認証情報は含めない。

これは**映像カタログではない**。GPSとの時刻対応に必要な動画の開始時刻・尺・
カメラ時計補正は、次の明示的なメタデータ確認工程で別に確定する。棚卸しだけで
映像の内容や編集適性を判断してはならない。

## 実行

### ローカル画面（推奨）

`http://127.0.0.1:8765/local-media-inventory`を開き、動画フォルダを選択して
**棚卸しJSONを作成**を押す。専用ページはGoogle Mapsを含む外部スクリプトを
読み込まず、選択情報をローカルサーバーにも送らない。ブラウザ内でファイル名、
相対パス、サイズ、更新時刻だけからJSONを作り、Macへ直接ダウンロードする。
動画本体を読み取るAPIは使用しない。

### コマンドライン

実動画を含むフォルダと、Git管理外の保存先を明示して実行する。

```bash
python -m app.video.inventory "/実動画の親フォルダ" \
  --output "/実動画と同じ非公開領域/private-media/ride-storyteller-local-video-inventory.json"
```

- 対象は`.mp4`、`.mov`、`.lrv`（大文字・小文字を問わない）。サブフォルダも対象にする。
- シンボリックリンクはたどらない。
- 既存の出力ファイルは上書きしない。内容を更新するときだけ`--overwrite`を明示する。
- `private-media/`と標準の出力ファイル名は`.gitignore`で除外する。ただし、出力先自体も公開リポジトリ外にする。

## 次工程

1. 棚卸しJSONから、ファイル数・合計容量・形式の分布だけを確認する。
2. 選んだ短い区間について、ローカルで開始時刻・尺・フレームレートを確認する。
3. GPS時計との差を計測し、確認済みの値だけで私用動画カタログを作る。
4. Story Agentが要求した候補区間だけを低解像度プロキシにし、外部サービスへ送る場合はその都度明示承認を得る。

## 1ファイルの技術メタデータ確認

棚卸し後、必要な動画だけについて、開始時刻・尺・コーデック・解像度・フレーム
レート・音声有無をローカルで確認できる。これは動画コンテナのヘッダーを読むため、
棚卸しとは異なり対象の動画ファイルを開く。ただし映像をデコード・アップロード・
共有せず、外部ネットワークにも接続しない。

この処理にはMacに`ffprobe`（FFmpeg付属）が必要である。2026-08-16の開発Macには
未導入のため、インストール前には実行できない。インストールは別の明示承認後に行う。

```bash
python -m app.video.probe "/実動画の親フォルダ/GX010001.MP4" \
  --output "/実動画と同じ非公開領域/private-media/GX010001-metadata.json"
```

`creation_time`が取得できても、GPSとの一致を保証するものではない。カメラ時計の
タイムゾーンとGPS時計との差をローカルで確認するまで、結果を時刻対応カタログへ
自動登録してはならない。
